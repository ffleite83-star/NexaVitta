# NexaVitta

> Estamos aqui para caminhar com você até o próximo passo.

Este repositório inaugura o Brand Book digital da NexaVitta: uma plataforma que busca tornar o início do cuidado em saúde mental mais humano, claro e menos solitário.

## Primeira versão

Uma página estática, sem dependências de build, pronta para publicação em qualquer host estático. Ela estabelece:

- a proposta e o manifesto da marca;
- o sistema visual de pontos, linhas curvas e trajetórias;
- a primeira versão do símbolo em SVG;
- cores, tipografia e tom de comunicação.

Abra `index.html` localmente ou publique o repositório na Vercel.
