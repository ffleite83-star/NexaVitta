# NexaVitta

> Estamos aqui para caminhar com você até o próximo passo.

Brand Book digital da NexaVitta: uma plataforma que busca tornar o início do cuidado em saúde mental mais humano, claro e menos solitário.

## Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · Framer Motion · MDX. Deploy: Vercel (zero-config).

## Rodando localmente

```bash
npm install
npm run dev
```

## Estrutura

```
docs/       → documentação interna (fundação, arquitetura, roadmap, changelog)
brand/      → guia de marca (cor, tipografia, fotografia, iconografia, movimento)
content/    → conteúdo MDX das páginas do Brand Book
app/        → rotas Next.js
components/ → componentes de UI reutilizáveis
public/     → assets estáticos
```

Comece por `docs/00_FOUNDATION.md` para entender a filosofia antes de mexer em qualquer código.
