# 00 · Fundação

NexaVitta = Nexa (conexão) + Vitta (vida).

Nosso propósito não é conectar pessoas com psicólogos. É caminhar com as pessoas até o próximo passo de sua jornada.

A tecnologia é o meio. A confiança é o produto. A IA é invisível. O protagonista é sempre o paciente; o psicólogo é quem transforma vidas. A NexaVitta constrói o caminho.

Compromissos permanentes:
- Jamais prometemos cura.
- Jamais prometemos diagnóstico.
- Jamais substituímos profissionais.
- Jamais vendemos falsas certezas.

Promessa: "Estamos aqui para caminhar com você até o próximo passo."

Toda decisão de produto responde a uma pergunta: isso aumenta a probabilidade do usuário dar o próximo passo? Se não, não implementamos.

Este documento é a fonte da verdade. Quando houver dúvida sobre qualquer decisão de produto, marca ou engenharia, volte aqui antes de decidir.
