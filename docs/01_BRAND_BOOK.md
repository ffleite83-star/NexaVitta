# 01 · Brand Book

O Brand Book é o primeiro produto da NexaVitta — publicado antes de qualquer funcionalidade comercial, em `app/` com conteúdo em `content/*.mdx`.

## Estrutura publicada

/, manifesto, quem-somos, missao, visao, valores, personalidade, voz, direcao-criativa, sistema-visual, produto, arquitetura, ia, roadmap, changelog — ver `lib/pages.ts` para a definição canônica de ordem e agrupamento.

Cada página é um documento vivo: o conteúdo evolui em pull requests normais, versionado junto com o código, e mudanças relevantes são registradas em `10_CHANGELOG.md`.

Ver também `02_MANIFESTO.md` para o texto fundador completo e `brand/` para o guia de estilo visual aplicado.
