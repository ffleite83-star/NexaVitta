O design system da NexaVitta nasce junto com o primeiro commit, não depois. Ele existe para que cada nova página pareça inevitável, não desenhada do zero.

## Cor

| Token | Uso |
|---|---|
| `ink` `#172838` | Texto principal, fundo de destaque |
| `ink-soft` `#365263` | Texto secundário |
| `paper` `#f6f5ef` | Fundo padrão |
| `sand` `#e9e6da` | Superfícies alternativas |
| `sage` `#c0d2a2` | Acento — início da jornada |
| `blue` `#6599a2` | Acento — meio da jornada |
| `violet` `#5967a6` | Acento — continuidade |

## Tipografia

Manrope para texto de interface (clareza, neutralidade). Playfair Display itálico reservado para uma única ênfase por seção — a frase que carrega o sentimento central daquele trecho.

## Movimento

Framer Motion é usado com intenção, nunca decoração: a curva da trajetória se desenha, os pontos aparecem em sequência. O movimento representa a própria filosofia — nada acontece de uma vez, tudo é passo a passo.

Ver detalhes completos em `brand/colors.md`, `brand/typography.md` e `brand/motion.md`.
